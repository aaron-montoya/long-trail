# Long Trail

Browser playtest table for **Long Trail**, a sled-dog racing card game for 2–4 players.

Play: open `index.html` (or the GitHub Pages site). Each seat can be a human (hot-seat, pass the screen) or a bot.

- `index.html` – the whole game (rules engine, bots and UI) in one file
- `art/` – card images (WebP) and `manifest.json` mapping card file names to images
